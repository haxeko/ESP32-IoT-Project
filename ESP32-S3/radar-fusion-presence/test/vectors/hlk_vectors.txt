# Byte streams and the events the decoders must produce from them. Shared by the
# C++ host tests (test/host) and the Python tests (tools/tests), so both decoders
# give the same answers. Each test feeds a stream whole, byte by byte and in
# 7-byte chunks; every way must give the same events and counters.
#
# name | stream (hex, spaces ignored) | events, separated by " ; " (empty: none) | parser counters (optional)
#
# Events:
#   R2410 t=type st=state mcm= me= scm= se= dcm= [nm= ns= m=gate energies s=gate energies] x=extra bytes [light= out=]
#   E2410 err=<decode error>
#   R2450 n=targets t1=x,y,speed,resolution|- t2=... t3=...   (a trailing * marks an implausible target)
#   ACK c=command st=status v=value hex   EACK err=<decode error>
#   CMD c=command v=value hex             (a command frame: our TX looped back)
# Counters: frames garbage bad_length bad_footer
#
